JavaScript originated in web browsers. The first browser was Mosaic, developed by NCSA in 1992, which was the precursor to browsers later developed by Netscape (now Mozilla). In 1995, Brendan Eich created JavaScript at Netscape as a scripting language for web pages. Together, HTML (for content), CSS (for styling), and JavaScript (for behaviour) form the core foundation of modern web front-end development.

The term "script" originally implied that the code did not run as a standalone program, but was executed by a host environment to perform customised tasks, such as handling user interactions on web pages. Today, every modern browser includes a JavaScript engine (interpreter), such as Google Chrome's V8, Mozilla Firefox's SpiderMonkey, and Apple Safari's JavaScriptCore. Moreover, starting with Node.js, which also uses V8, hosts for JavaScript have expanded far beyond browsers, allowing JavaScript to run across various server and edge runtimes, such as Deno, Bun (JavaScriptCore), as well as serverless platforms like Vercel's Edge Runtime and Cloudflare Workers.

In 1997, JavaScript was standardised by ECMA as ECMA-262, commonly known as ECMAScript (ES). Notable milestones include ECMAScript 3.0 (1999), ECMAScript 5.1 (2011, ISO/IEC 16262), ECMAScript 6 (2015), ECMAScript 2017 (ES8), and ECMAScript 2020 (ES11).

JavaScript supports both object-oriented and functional programming paradigms. Its syntax is influenced by Java (C/C++), its first-class functions are derived from Scheme, and its prototype-based inheritance is inspired by Self.
